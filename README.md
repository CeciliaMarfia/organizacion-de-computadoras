# Organización de Computadoras

Material teórico-práctico de Organización de Computadoras (Facultad de Informática, UNLP).

## Estructura

- `teoria/`: diapositivas de las clases teóricas.
- `practica/`: prácticas, resoluciones y explicaciones de práctica.
- `parciales/`: parciales de años anteriores.
- `final/`: material para preparar el final.

## Temas

- Computadoras digitales: modelo de von Neumann, rendimiento y niveles de abstracción
- Aritmética: enteros con y sin signo, punto flotante (IEEE 754), ASCII
- Lógica digital: álgebra de Boole, lógica combinatoria y secuencial
- CPU: ciclo de instrucción, modos de direccionamiento, lenguaje assembly
- Memoria y periféricos: jerarquía de memoria, almacenamiento externo, RAID

---

Las resoluciones son propias y pueden tener errores. El material de cátedra (diapositivas, enunciados y parciales) pertenece a sus docentes y está incluido solo como referencia de estudio.
